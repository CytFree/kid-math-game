# 自定义出题 + 家长练习集 设计

**日期**: 2026-05-26 | **状态**: 设计中

## 背景

当前所有出题由系统自动生成（对话动物、故事、冒险），缺少让小朋友自主选择
或家长定制练习路径的能力。

## Part 1：小朋友自定义出题

### 入口

和动物对话弹窗中，现有"帮小橘解题"按钮下方新增"✏️ 我想自己出题"按钮。

点击后关闭对话弹窗，进入自定义出题页面。

### 自定义出题页面 (`custom-screen`)

布局复用题目页结构（header + card），内容分为三个区域：

**1. 运算类型选择**（三选一）
- ➕ 加法 / ➖ 减法 / 🎲 混合
- 大按钮横排，点击高亮。默认选中加法

**2. 数字选择**
- 两行数字按钮，每行 1-10
- 第1行标签"第一个数"，第2行标签"第二个数"
- 点击高亮（蓝底白字）
- 减法时：选择第1个数后，第2个数自动限制 ≤ 第1个数（超出部分置灰不可选）
- 切换运算类型时，重置数字选择

**3. 预览行**
- 实时显示已选参数的算式：`3 + 2 = ? 🐟`
- emoji 自动继承对话动物的 items（如小橘=🐟，旺财=🦴）

**4. 开始按钮**
- 两个数字都选好后，"🚀 开始做题"按钮亮起
- 未选完时灰色不可点击

### 进入题目流程

点击开始 → 调用 `startQ(mode, aid, teach, total)` 进入现有 q-screen：
- `mode`: `'custom'`
- `teach`: 根据选中的类型映射（加法→add, 减法→sub, 混合→mix）
- 题目数量：无限循环（total=999），做完一题出下一题，点击退出回到岛屿
- genQ 使用自定义的 teach 模式 + 选中的数字作为 nums

题目页的操作区、答案选项与现有流程完全一致，Lv.7 分解树自动适配。

### genQ 适配

新增 `genQ` 重载：当 mode='custom' 时，跳过随机生成逻辑，直接使用小朋友选定的
数字和类型：

```
if (mode === 'custom') {
  nums = [customNum1, customNum2];
  op = customOp;  // '+' or '-'
  ans = op === '+' ? nums[0] + nums[1] : nums[0] - nums[1];
  // mix 模式：随机决定本次用 + 还是 -
}
```

## Part 2：家长练习集

### 家长门控

岛屿 HUD 的 ⚙️ 按钮：短按无效，需**长按 3 秒**才能进入家长面板。
（防止小朋友误入）

### 练习集设置页 (`practice-set-screen`)

**参数设置**：
- 运算类型：加法 / 减法 / 混合
- 第1个数字范围：1 ~ ? (1-10)
- 第2个数字范围：0 ~ ? (0-10，减法时自动 ≤ 第1数范围)
- 题目数量：5 / 10 / 15 / 20

**生成按钮**："📋 生成练习集"

**生成逻辑**：调用 genQ 批量生成，每道题自动校验 10 以内：
- 加法：a + b ≤ 10
- 减法：a ≥ b，a ≤ 10
- 混合：随机 ±，各自满足规则

### 存储

```javascript
var PRACTICE_SET_KEY = 'mi2_practice_set';
// 存储结构:
{
  type: 'add' | 'sub' | 'mix',
  num1Min: 1, num1Max: 10,
  num2Min: 0, num2Max: 9,
  total: 10,
  questions: [{nums, op, answer, emoji, story}, ...],
  progress: { done: 0, correct: 0 },
  createdAt: timestamp
}
```

每次生成新练习集会覆盖旧练习集（同时只存一份）。

### 孩子练习入口

岛屿 HUD 上，有练习集时显示 📝 按钮。点击开始逐题练习。

复用 q-screen 流程：startQ('practice') → genQ 从练习集 questions 数组中
按 progress.done 顺序取题。

**完成总结**：做完所有题后弹窗显示：
- 正确数 / 总题数
- 🌟 星级评价（全部对=3星，≥80%=2星，其余=1星）
- "再来一次" / "返回岛屿"按钮

## 不做的事

- 不做打印/导出 PDF
- 不把自定义参数存 localStorage（每次重新选即可）
- 不改变现有故事/冒险/对话出题的逻辑
- 不改变操作区和 Lv.7 分解树
